# Переносной архив проекта

Структура:
- docs/ — замысел, решения, экономика, этапы, архитектура, передача агенту;
- AGENTS.md — проектные правила общения и работы;
- art/concepts/ — актуальный утверждённый художественный ориентир;
- art/references/ — исходные фотореференсы с происхождением;
- art/models/ — актуальные .blend;
- art/textures/ — художественные текстуры (пока пусто);
- art/renders/ — актуальные PNG и технические параметры;
- art/production/ — действующий скрипт и инструкция воспроизведения;
- tools/backup.py — сборка ZIP без пароля, манифестSHA256 и проверка.

В архиве только текущие выбранныеверсии town-v2/panel-v3. V1остаётся локально.
Полная документация входит. Blender1,5ГБ не входит; версия4.5.9LTS и инструкции
записаны в productionREADME. Скрипты с абсолютными путями адаптировать после переноса.
Этот архив резервирует проектные исходники, не снимок всегоVPS и не игровыхданных
(их ещё нет). Работоспособность восстановления игры пока проверить невозможно.

Запуск: python3 tools/backup.py /workspace/outbox
Результат ZIP и соседнийSHA256файл. Проверить ZIP по testzip и каждомуфайлу
manifestSHA256; SHA256самого ZIP записан отдельно. Пустаяпапкаtexturesсохраняется.

  `/home/mike/living-town-hub/towns.sqlite`; гостевой8798 и его база сохранены.

Браузер использует HttpOnly hub_access cookie. Сервер проверяет Ed25519-подпись
публичным ключом id, issuer, срок и право town. Он не получает приватный ключ
хаба и не хранит почту. Идентификатор персонажа выведен из проверенного sub.
Новый телефон после входа по той же почте получает того же персонажа.
Город один, предел первой версии —10учёток, отдельные тестовые города в боевом
режиме создавать нельзя. Вознаграждение/покупки/позиция сохраняются на сервере.
Гостевые ссылки/куки доступа не дают. Первоначальный мир создаётся при первом
авторизованном входе, старые гостевые данные не копируются и не удаляются.

Если access истёк, клиент обращается к id /api/auth/refresh и повторяет запрос.
SSE прекращает выдачу после срока пропуска; клиент обновляет вход и подключается
снова. При недоступности id показывается ошибка связи, а не бесконечный вход.
При возвращении из хаба проверяется аккаунт; смена аккаунта перезагружает игру.
Фокус сам по себе не закрывает игровой поток и не прекращает ремонт.
Прочие ограничения версии онлайн и сохранения маршрутов — в ONLINE-V1.md.

## Установка

Манифест, иконки192/512, standalone, start_url/scope=/, кнопка установки.
Где системный prompt недоступен, показывается инструкция меню браузера; iOS —
Safari→Поделиться→На экран Домой. Физические Android/iOS агентом не проверены.
Это онлайн-игра: SW кэширует только нейтральную offline.html. API, учётки и
снимки города в CacheStorage не сохраняет. При навигации без сети — объяснение
и ссылка повторного открытия; после восстановления сети возвращается аккаунт.

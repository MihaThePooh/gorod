# Первая локальная сцена (исторический этап)

Актуальная сцена дополнена строительным заказом: [CONSTRUCTION-V1](CONSTRUCTION-V1.md).
Ниже сохранено описание исходного прототипа до покупки материалов и ремонта.

## Что работает

Canvas2D без сборки и внешнихCDN: client/index.html/style.css/game.js/assets.
СтатическийHTTPсервер доставляет файлы; вся текущая симуляция в браузере.
Это НЕ игровойавторитетныйсервер, НЕмультиплеер, НЕперсистентныйобщийгород.
Нет аккаунтов, экономики, покупки/стройки, реальноговремени/погоды. Часы14:30
вHUD пока статичны. Страницапоказываетпервуюпроверкумасштаба/управления.

- Три экземпляра утверждённой панельки, земля, три типа дороги и берёзы.
- Управление нажатием на землю, WASD/стрелки (также русскаяраскладка).
- Поиск пути по сетке1м с запретом срезать угол здания. Местные коллизии.
- Персонаж следует маршруту со скоростью3,2м/сек; кнопка«Молоток»демонстрирует
  рабочуюанимацию. Это не строительныйзаказ и не выдача награды.
- Плавноследящаякамера, перетаскиваниеобзора, возвраткперсонажу, зум0,3–1.
- Колесомыши/плюсминус/ползунок/двупальцевыйжест. Наклонкамерыфиксирован.
- Дом полупрозрачен для персонажа за ним. Позициянесохраняетсямеждусеансами.

## Локальный запуск

`python3 -m http.server 8790 --directory client` изкорняпроекта.
Открыть http://127.0.0.1:8790/ . Это адреслокальноймашинызапуска, не публичный.

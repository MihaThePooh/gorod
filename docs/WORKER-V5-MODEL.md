# Worker-v5 — новая геометрия по видео

Поручение Михаила18.11: заменить прежнюю модель формой из Telegram-видео2352e822…mp4. Источник приватный: art/references/worker-model-v5/reference.mp4,31.06с/720×1280. Ключевые ракурсы осмотрены в overview.jpg; речь передана готовым транскриптом пользователя. Сторонние сервисы/платные модели не использованы.

Это процедурная реконструкция пропорций и одежды, не исходная сетка из сервиса и не точная фотограмметрия. Кандидат остаётся упрощённее референса, особенно лицо и мелкие складки; не объявлять одобренным или точной копией.

Генератор art/production/build_worker_v5.py загружает worker-v4.blend только как основу скелета, удаляет в своей сцене старые меши, строит новые через worker_mesh_v5.py. Добавлены локальные складки, воротник, молния, карманы, подошва. Куртка/брюки объединены voxel-remesh0.004м, сглажены, веса перенесены ближайшими вершинами и нормализованы. Нейтральный материал специально для проверки геометрии. Прежниеv3/v4и игровые атласы сохранены.

art/models/worker-v5.blend — редактируемая модель; client/worker-model-v5/worker-v5.glb — отдельный3Dпросмотр. ГрафикаGLBэкспортирована собственным export_worker_glb_lite.py. Это плотный источник для последующих2Dспрайтов, не оптимизированная realtime-игровая сетка. Движениеv4ещё не перенесено на новые пропорции: понадобится подгонка суставов и проверка деформаций после одобрения формы. Вblend22-костныйskin; веб-GLBоблегчёнdecimateиэкспортированстатическимбезскина/анимации. Генераторпослесборкинужнообработатьexport_worker_model_v5.py. Viewerрисуеттолькоприповороте/изменении,безпостоянногоциклакадров. Наличиескелетавblendнеозначаетготовуюанимацию.

QA: tools/check_worker_model_v5.py, фактический qa.json вart/renders/worker-v5; проверяются конечные координаты, ненулевые грани, замкнутостькомпонентов, наличиевесов, числоvertices/tris/bounds. Не проверяетсяавтоматическисходствосреференсом,UV/запекание/всеанимационныепозы. Внешнийblender-asset-qaнеустановлен, локальнаяпроверканезаменяетручнуюретопологию.

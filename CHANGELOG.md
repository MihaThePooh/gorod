# История рабочих версий

## v3 — 19.11.2026

- Выполненный заказ уходит из активной карточки; рамка и метка стройки убираются.
- Результат, расчёты и журнал доступны через «Заказы». При отсутствии новых работ
  об этом сказано явно. Свежий асфальт сохраняет отличие от изношенной дороги.

## v2 — 19.11.2026

- Поза шага включается одновременно с видимым движением, без застывшего
  первого кадра в ожидании буфера. Проверены старты, остановки и повторный ход.
- Обновление только клиента больше не перезапускает неизменённый backend.

## v1 — 19.11.2026

Первая сохранённая в GitHub версия действующей игры https://gorod.michaelperov.com/.

- Общий посёлок и персонаж, привязанный к аккаунту хаба; вход по коду на почту.
- Один строительный заказ: покупка и доставка щебня, совместный ремонт, оплата.
- Сервер проверяет маршруты, действия и расчёты; SQLite сохраняет мир и деньги.
- Российская пятиэтажка, рабочий, дороги, трава и берёзы; камера с приближением.
- PWA и установка на телефон; для общего города нужен интернет.
- Сглаживание сетевого движения и камеры, отрисовка объектов в пределах экрана.
- Постоянное WAL-соединение, контроль времени симуляции, немедленные денежные
  транзакции и периодическое сохранение позиции.

Проверки: 11 серверных, 3 сетевого сглаживания и 4 одиночного заказа; публичный
кооп двумя игроками, одна оплата270/270, перезагрузка, фон, вход/PWA и SHA файлов.

Кандидаты новых моделей рабочего не заменяют действующий игровой спрайт.

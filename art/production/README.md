# Пятиэтажка: первый производственный прототип

Blender4.5.9LTS скачан с download.blender.org, архив проверен по официальномуSHA256.
Локальная установка в /projects/tools/blender-local, без изменения системных пакетов.

Запуск из рабочего окружения:

```sh
sh /projects/work/living-town/art/production/render-panel.sh
```

Выход: art/models/panel-v1.blend, art/renders/panel-v1.png с альфа-каналом,
art/renders/panel-v1-metadata.json. Это геометрический прототип; рисованный
стиль концептаv2 ещё не воспроизведён. Размеры являются игровой интерпретацией
фотореференсов, не архитектурными обмерами. Фасад балконов и входов готовится
для одного пробного ракурса; оборотный фасад нужно доработать для других камер.

Скрипт строит меши пакетами по материалам, фиксирует seed17, затем сохраняет
модель и рендерит CPU Cycles24samples/2threads. Параметры W,D,H и число этажей
пока находятся в коде; полноценный пользовательский генератор ещё не готов.
Сначала проверяем пропорции и ракурс. Затем дорабатываем материалы, модульность,
параметры и экспорт точек привязки/коллизий для игры.

В изоляции отсутствуют X/GL runtime-библиотеки, даже для headless запуска.
Недостающие библиотеки распакованы локально из пакетов Ubuntu noble/main,
SHA256 пакетов проверены по Packages.gz. Несколько имеющихся библиотек
скопированы с хоста в runtime-libs; системные пакеты не устанавливались.
Загрузчик в render-panel.sh задаёт пути только для запуска Blender.

## Камера v2

По правке Михаила высота камеры относительно точки прицеливания уменьшена
с85до51 (-40%) при тех же горизонтальных координатах32/-45.
Угол к земле меняется примерно с57до43градусов. Геометрия, свет, материалы,
масштаб ортографической камеры и seed сохранены. Отдельный скрипт
build_panel_v2.py создаёт panel-v2.blend/PNG/metadata, не перезаписываяv1.

Актуальная утверждённая версия: panel-v2. Команда render-panel.sh теперь
запускает build_panel_v2.py. Упоминанияv1выше — история первого прототипа,
его модель и генератор в актуальный переносной архив не включаются.
